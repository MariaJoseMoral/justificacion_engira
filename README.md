# justificacion_engira

Motor para elaborar una justificación trazable a partir de documentación externa.

- `engine/`: código, configuración, pruebas y salidas organizadas por fase.
- `../datos_engira/`: documentación de entrada del expediente; nunca se añade al
  repositorio.

El punto de entrada y la estructura de resultados están documentados en
[`engine/README.md`](engine/README.md).
